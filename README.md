# Color Links

Calm grid puzzle. Join each pair of matching dots and fill every cell. Paths stay on the grid lines, and they cannot cross. Portrait only.

Package: `com.arusoft.colorlinks`  
Firebase project id: `arusoft-color-links`

```bash
flutter test
flutter run
```

Web preview, from this folder:

```bash
APP_ROOT=. ../lib/scripts/run_web.sh
```

Release notes template lives in `play/whatsnew.txt`. Shared scripts stay in `mobile-apps/lib` and are not copied here.
